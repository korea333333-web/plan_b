# 제품 명세 — 현재 MVP

## 1. 제품 정의

**매화수련록**은 계획을 직접 적거나 간단한 규칙으로 자동 분배하고, 종료된 일정의 실행 여부와 누적 기록을 확인하는 개인용 웹 계획표다.

현재 제품은 로그인 없는 단일 브라우저 경험에 맞춰져 있다. 반응형 UI는 모바일과 PC를 모두 지원하지만 데이터가 기기 사이에서 자동 동기화되지는 않는다. 저장 방식은 배포 환경에 따라 D1 또는 브라우저 `localStorage`를 사용한다.

## 2. 화면 구조

`/` 한 페이지 안에서 다음 세 탭을 전환한다.

1. **내 계획표**
2. **계획 만들기**
3. **수련 기록**

페이지를 새로고침하면 첫 탭인 내 계획표로 돌아온다. 별도 `/create`, `/records` 주소나 브라우저 뒤로가기 이력은 없다.

모바일은 하단 고정 내비게이션, PC는 좌측 사이드바를 사용한다. 기기 종류를 묻지 않고 화면 폭으로 바뀐다.

## 3. 내 계획표

### 빈 상태

- 현재 환경에서 이 브라우저가 읽을 계획이 없으면 `아직 계획이 없습니다.`를 표시한다.
- `계획 만들기` 버튼으로 작성 탭을 연다.
- 검술·명상·서예 같은 시안용 일정은 기본 데이터로 넣지 않는다.

### 주간 보기

- 월요일부터 일요일까지 한 주를 표시한다.
- 이전 주·다음 주로 이동할 수 있다.
- 06:00부터 24:00까지 세로 시간표를 보여 준다.
- `30분 / 1시간`은 화면의 눈금 높이만 바꾼다.
- 모바일에서는 넓은 주간표가 카드 내부에서 가로·세로 스크롤된다.
- 일정 카드를 누르면 날짜, 시간, 상태, 메모와 삭제 버튼이 있는 상세 시트가 열린다. 반복 일정의 삭제 버튼은 `반복 계획 전체 삭제`로 표시하며 모든 회차를 함께 삭제한다.

### 오늘 보기

- 오늘 발생하는 일정만 시간순으로 보여 준다.
- `표 / 원` 보기로 전환할 수 있다.
- 표 보기에서는 종료되어 미확인이 된 일정에 `완료했어 / 못 했어` 버튼이 나온다.
- 원형 보기는 24시간 안의 일정 구간과 텍스트 범례를 보여 준다.
- 오늘의 전체 계획 수, 완료 수, 미확인 수를 간단히 표시한다.

## 4. 계획 만들기

### 직접 작성

입력값:

- 계획 이름
- 날짜
- 시작·종료 시간
- 반복 요일(선택)
- 분류 색상
- 메모(선택)

종료 시간은 시작 시간보다 늦어야 한다. 반복 요일을 고르면 기준 날짜 이후 해당 요일에 같은 일정 행이 계속 표시된다. 반복 종료일은 현재 지원하지 않지만, 각 발생 날짜의 완료·미완료 상태는 서로 독립적으로 저장된다.

저장하면 현재 환경의 저장소에 계획 한 건을 만들고 내 계획표 탭으로 돌아간다. 로컬·Sites는 D1, Vercel은 브라우저 `localStorage`를 사용한다.

### 자동 생성

입력값:

- 할 일 이름과 총 소요 분
- 시작일과 마감일
- 가능한 요일
- 공통 가능한 시작·종료 시간
- 하루 최대 1–4시간
- 계획 단위 30분 또는 1시간

자동 생성기는 입력 순서의 할 일을 선택 기간에 가능한 날짜로 고르게 분배한다. 가능한 시간이 부족하면 배치하지 못한 분량을 알려 준다.

현재 동작:

- 기존에 저장된 일정과의 충돌은 검사하지 않는다.
- 생성 결과는 읽기 전용 미리보기이며 항목별 수정·삭제는 없다.
- 화면에는 미리보기 최대 12개를 보여 주지만 저장 버튼은 생성된 전체 항목을 저장한다.
- 로컬·Sites 저장은 일정별 POST를 순서대로 실행한다. 중간 실패 시 앞서 저장된 일부 일정이 D1에 남을 수 있다.
- Vercel 저장은 브라우저 `localStorage`에만 반영되며 서버에 업로드되지 않는다.

## 5. 일정 상태와 캐릭터 반응

화면 상태:

- `예정`: 종료 전
- `미확인`: 종료 후 사용자가 아직 판정하지 않음
- `완료`
- `미완료`

`예정` 일정은 판정할 수 없다. 시간이 지나면 화면에서 `미확인`으로 계산되며 자동으로 `미완료`가 되지 않는다. 반복 일정은 선택한 발생 날짜만 완료 또는 미완료로 판정되고, 다른 날짜의 같은 반복 일정은 바뀌지 않는다. 비반복 일정은 계획 행의 기존 상태를 사용한다. 현재 UI는 한 번 완료 또는 미완료로 판정한 뒤 다시 정정하는 기능을 제공하지 않는다.

판정하면 현재 브라우저 세션 안에서 청명 → 백천 → 유이설 → 조걸 → 윤종 순으로 한 명씩 등장한다. 순번과 등장 인물은 어느 저장 경로에도 영속화되지 않아 새로고침하면 청명부터 다시 시작한다.

### 확정 대사

| 인물 | 완료 | 미완료 |
|---|---|---|
| 청명 | `오, 좀 하는데?` | `어디서 할 일을 빼먹고 있어? 뒈지려고?` |
| 백천 | `잘했다. 네가 정말 자랑스럽다.` | `네가 처한 상황이 지금 한가해 보이냐? 빨리빨리 해!` |
| 유이설 | `할 일은 잘하네. 착해.` | `느려. 빨리 해.` |
| 조걸 | `이건 청명이도 인정하겠는데?` | `앞으로 잘해! 청명이한테 찍힌다.` |
| 윤종 | `정말 고생 많았다. 네가 잘할 줄 알았다.` | `도망친다고 될 일이 아니다. 다음에는 꼭 하거라.` |

오늘의 미확인 일정이 있으면 화산오검 다섯 인장을 함께 표시하고 다음 문구를 쓴다.

> `뭐야, 왜 안 왔어?`

사진은 사용하지 않고 이름의 첫 글자를 넣은 인장으로 표현한다.

## 6. 수련 기록

현재 기록 탭은 비반복 계획과 반복 계획의 발생 회차를 기준으로 다음을 표시한다.

- 전체 완료율
- 연속 달성 일수
- 미확인 개수
- 미완료 개수
- 매화 개화 시각화
- 최근 발생일 기준 판정 회차 최대 6개

계산:

- 완료율 분모는 사용자가 판정한 비반복 계획과 반복 회차의 `완료 + 미완료`만 포함한다.
- 예정과 미확인은 완료율 분모에서 제외한다.
- 연속 달성과 미확인 개수는 최대 최근 365일의 발생 회차를 만든 뒤 계산한다.
- 연속 달성은 이 범위에서 일정이 있는 날짜만 역순으로 보며, 모두 완료된 날짜를 센다.
- 미완료 또는 미확인이 있는 날짜에서 연속 기록이 끊긴다.
- 오늘에 예정 일정만 있으면 오늘을 건너뛰고 이전 기록부터 계산한다.
- 매화 개화율은 현재 주에 발생하는 회차의 완료율을 사용한다.

월간 통계와 사용자 지정 기간 필터는 현재 제공하지 않는다.

## 7. 저장과 재방문

### 로컬 개발과 OpenAI Sites

- vinext와 Cloudflare D1을 사용한다.
- 첫 접속 시 브라우저 `localStorage`에 임의의 `maewha-client-id`를 만든다.
- 계획은 이 ID와 함께 서버의 D1 `plans` 테이블에 저장된다.
- 같은 사이트의 같은 브라우저 프로필에서는 같은 ID로 D1 계획을 다시 불러온다.
- ID 자체가 브라우저에만 있으므로 다른 기기나 브라우저에서는 같은 D1 행을 자동으로 찾지 못한다.
- D1 API가 실패하면 안내를 띄우고 현재 브라우저 저장으로 전환한다. 이때 만든 계획은 D1 계획과 자동 병합되지 않는다.
- `occurrenceStatuses`를 추가하는 migration에서는 기존 반복행의 전역 상태를 `planned`로 초기화한다. 기존 비반복행의 상태는 유지한다.

### Vercel

- Next.js의 `next build` 경로로 배포한다.
- 계획 데이터는 해당 Vercel 도메인의 브라우저 `localStorage`에 저장된다.
- Vercel 저장은 D1, 서버 데이터베이스, 계정 백업이 아니다.
- 새로고침 후에는 유지되지만 다른 브라우저·프로필·기기로 전달되지 않는다.
- 사이트 데이터 삭제, 시크릿 창 종료 또는 도메인 변경 시 계획을 잃을 수 있다.

### 공통 제한

- 로그인, 계정 복구, 교차 기기 동기화, 사용자 소유권 검증은 없다.
- 30분/1시간, 주간/오늘, 표/원 선택과 캐릭터 순번은 저장하지 않는다.

## 8. 현재 범위 밖

- 친구, 응원, 순위표
- 로그인과 계정
- 모바일·PC 및 브라우저 간 데이터 동기화
- 캐릭터 사진과 웹툰 원본 이미지
- 일정 편집 및 판정 정정
- 자동 생성 미리보기 편집
- 기존 일정 충돌 회피
- 자동 계획 원자적 일괄 저장
- 월간·기간별 상세 통계
- 알림, 외부 캘린더 연동, 드래그 앤 드롭

## 9. MVP 승인 기준

- 빈 상태와 세 탭이 보인다.
- 직접 작성한 계획이 같은 브라우저에서 새로고침 후 유지된다. 로컬·Sites에서는 D1, Vercel에서는 `localStorage`에서 읽는다.
- 자동 생성 미리보기, 부족 분량 경고, 순차 저장이 작동한다.
- 주간/오늘, 30분/1시간, 표/원이 실제로 전환된다.
- 종료된 일정은 미확인으로 보이고 완료·미완료 판정과 대사가 작동한다.
- 기록 탭이 비반복 계획과 반복 계획의 발생 회차 기준 통계를 표시한다.
- 친구 메뉴와 예시 수련 일정, 원격 캐릭터 이미지는 없다.
