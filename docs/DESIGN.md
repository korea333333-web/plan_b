# 디자인 명세 — 현재 MVP

## 1. 방향

Stitch 시안의 한지, 먹, 매화, 수묵 산맥, 낙관 인상을 반응형 웹 UI로 재해석한다. 특정 웹툰 장면이나 얼굴을 복제하지 않고, 차분한 무협 문집과 현대 계획표가 섞인 분위기를 목표로 한다.

유지할 인상:

- 아이보리 종이 위의 먹색 글자
- 중요한 행동에만 쓰는 매화색
- 옅은 산수 배경과 떨어지는 꽃잎
- 둥근 종이 카드와 가는 테두리
- 모바일 하단 메뉴와 PC 좌측 책등형 메뉴

피할 것:

- 검술·명상 같은 가짜 예시 일정
- 영어가 섞인 미완성 문구
- 네온, 두꺼운 그림자, 과도한 게임 UI
- 웹툰 캡처, 얼굴 크롭, 로고, Stitch 원격 이미지

## 2. 실제 CSS 토큰

`app/globals.css`의 값이 단일 기준이다.

```css
--paper: #fbf6f1;
--paper-deep: #f1e9e2;
--paper-bright: #fffdfb;
--ink: #282421;
--ink-soft: #6c6660;
--line: rgba(63, 55, 49, 0.16);
--line-strong: rgba(63, 55, 49, 0.28);
--maewha: #ad344b;
--maewha-dark: #83263a;
--maewha-soft: #f1d9df;
--jade: #4f6b5b;
--gold: #b27b42;
```

- 매화색은 활성 탭, 저장 버튼, 현재 시각과 주요 강조에 쓴다.
- 비취색은 완료, 붉은색은 미완료, 중립색은 예정·미확인에 쓴다.
- 상태는 색만으로 구분하지 않고 한글 라벨을 함께 표시한다.

## 3. 글꼴과 표면

- 본문: Pretendard → Noto Sans KR → 시스템 산세리프
- 제목과 인장: Noto Serif KR 또는 바탕 계열
- 본문은 일정 정보가 읽히는 크기를 우선한다.
- 카드에는 종이색, 1px 테두리, 넓고 옅은 그림자를 사용한다.
- 붓글씨 느낌은 로고와 짧은 제목에만 한정한다.

## 4. 반응형 레이아웃

### 920px 초과

- 너비 258px 안팎의 좌측 사이드바
- 오른쪽에 본문
- 계획 만들기와 기록 카드는 가능한 경우 여러 열

### 920px 이하

- 상단 모바일 헤더
- 하단 3칸 고정 내비게이션
- 본문 하단에 내비게이션 높이를 고려한 여백
- 폼과 기록 상세는 한 열

### 620px 이하

- 페이지 제목과 보기 전환을 세로로 쌓는다.
- 기록 요약은 2열
- 오늘 원형 그래프와 범례는 한 열
- 주간표는 최대 높이 68vh인 내부 스크롤 영역을 쓴다.

모바일 주간표의 실제 보드 최소 폭은 790px이므로 가로 스크롤이 필요하다. 페이지 전체가 아니라 `.weekly-scroll` 안에서만 가로로 움직여야 한다.

## 5. 공통 컴포넌트

### 내비게이션

- 항목: 내 계획표 / 계획 만들기 / 수련 기록
- 활성 항목은 매화색과 옅은 배경으로 표시한다.
- 모바일은 한자 아이콘과 한글 라벨을 함께 쓴다.

### 전환 버튼

다음 전환은 같은 시각 언어를 사용한다.

- 주간 / 오늘
- 30분 / 1시간
- 표 / 원
- 직접 작성 / 자동 생성

활성 상태는 색과 배경을 함께 바꾼다.

### 입력과 버튼

- 주요 저장 버튼은 매화색 낙관형 버튼이다.
- 보조 동작은 종이색 외곽선 버튼이다.
- 입력 포커스에는 매화색 3px 윤곽이 보인다.
- 삭제는 조용한 X 또는 상세 시트의 텍스트 버튼으로 제공한다.

## 6. 화면별 구성

### 내 계획표

- 우측 상단에 주간/오늘 전환
- 주간 도구줄에 이전·다음 주와 30분/1시간
- 시간표의 오늘 강조, 현재 시각선, 색상 일정 카드
- 오늘 표 보기에 시간, 제목, 메모, 상태, 판정 버튼
- 오늘 원형 보기에 24시간 원과 텍스트 범례
- 일정 선택 시 화면 아래에서 상세 시트

### 계획 만들기

- 직접 작성과 자동 생성 탭
- PC에서는 입력과 미리보기 2열, 모바일에서는 세로 배치
- 자동 미리보기는 읽기 전용 목록이며 최대 12개만 화면에 보인다.
- 저장 버튼은 생성된 전체 결과를 저장한다.

### 수련 기록

- 전체 완료율, 연속 달성, 미확인, 미완료 요약 카드
- 전체 완료율을 사용한 매화 가지와 꽃 10개
- 최근 기록 6개
- 월간 그래프나 실제 주간 필터가 있는 것처럼 표현하지 않는다.

### 캐릭터 반응

- 사진 대신 이름 첫 글자 인장과 말풍선을 사용한다.
- 완료·미완료 판정 뒤 화면 우하단에 잠시 나타난다.
- 미확인은 오늘 화면에서 다섯 인장과 `뭐야, 왜 안 왔어?`를 함께 표시한다.

## 7. 배경과 움직임

- 고정된 옅은 산수 그라데이션 위에 꽃잎 14개가 떨어진다.
- 꽃잎은 `pointer-events: none`으로 입력을 막지 않는다.
- 620px 이하에서는 불투명도를 낮춘다.
- `prefers-reduced-motion: reduce`에서는 꽃잎을 숨기고 애니메이션·전환 시간을 사실상 제거한다.

## 8. 이미지 원칙

- 현재 배포에는 캐릭터 사진이 없다.
- `public/`, CSS, JSX에 Stitch의 Googleusercontent URL을 복사하지 않는다.
- 사진은 사용자가 나중에 적법하게 제공한 뒤 별도 작업으로 추가한다.
- 사진이 없어도 인장과 대사 레이아웃이 완성되어 보여야 한다.
